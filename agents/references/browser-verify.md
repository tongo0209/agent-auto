# Browser verify — chi tiết (frontend-developer)

> Core giữ luật bắt buộc. File này là recipe đầy đủ + ví dụ `run_steps` — đọc khi cần dựng lệnh browser hoặc khi một `expect_*` fail và phải chẩn đoán.

   - **Lỗi runtime không lộ ở terminal build** (`$ is undefined`, ảnh 404, lib CDN chưa nạp…): nếu môi trường có **BrowserPilot MCP** → mở trang (dist hoặc dev server) và kiểm tra trong **một** lần `run_steps` theo lô (goto → expect_visible các block chính → `expect_no_console_errors`), thay vì mở rồi "nhìn" lại từng bước. Ví dụ:
     `run_steps {"steps":[{"goto":"{{base_url}}/index.html"},{"expect_visible":".hero"},{"expect_visible":".cta-button"},{"expect_no_console_errors":true}]}`.
     Fail thì kết quả đã trả sẵn gói chẩn đoán (url, console errors, network failures, element gần giống, screenshot path) — ĐỌC gói đó để xác định lỗi (vd `$ is undefined`, ảnh 404), đừng vội `inspect` cả trang. Cần thêm network/console chi tiết thì gọi `read_signals`. Cần đánh giá visual thì `screenshot` (trả file path) rồi Read ảnh khi thật sự cần. **Chỉ có Playwright MCP** (không browserpilot) → dùng tool tương đương: `browser_navigate` mở trang → `browser_snapshot`/`browser_wait_for` khẳng định render → `browser_console_messages` lọc lỗi → `browser_resize` đổi viewport (mỗi action 1 call; xem bảng map đầy đủ trong `design-checker.md`). Không có browser MCP nào → ghi rõ trong report "chưa check runtime console".
   - **Kiểm responsive theo "Quy ước giao diện team" trong CLAUDE.md global** (nguồn luật DUY NHẤT: viewport PC/Mobile, reload 1 lần, H5 chỉ ngang, đóng/reset session sau test). Kỹ thuật: gom cả 2 vào CÙNG một `run_steps` bằng step `set_viewport` — chuyển PC → mobile reload đúng 1 lần vì JS layout init theo viewport lúc load: `{"steps":[{"set_viewport":{"width":1920,"height":1080}},{"goto":"..."},...verify PC...,{"set_viewport":{"width":768,"height":1024},"then_reload":true},...verify mobile...]}`. Spec nêu breakpoint khác → check thêm tương tự. **Ngoại lệ — trang H5** (webview in-game, khi spec/task nói là H5): chỉ verify **MỘT view duy nhất dạng ngang như PC (1920x1080)** — không check mobile, không cần reload chuyển viewport.
